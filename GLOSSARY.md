# Glossary

Observed vocabulary from baseline `8216155ac7f7d9cf3b7f4922093a7da58939beb0`,
updated for the standalone Angular 22 frontend and .NET 11 backend.
Meanings below describe this demo's code, not additional business requirements.
Paths are relative to the repository root. Existing `ToDo`/`Todo`/`todo` spelling
variants are aliases; preserve identifiers and wire names unless a scoped change
coordinates all consumers. Product naming decisions belong to the human owner.

| Canonical term | Meaning and code aliases | Source evidence |
| --- | --- | --- |
| LAND Stack | LiteDB, Angular, Nginx and .NET used together; repository name `LandStack`. | `README.md` |
| To-do item | A persisted task with GUID `ToDoItemId`, text `Description`, boolean `IsCompleted` and `CreatedDate`. Code aliases: `ToDoItem`, `todoItem`, `todo`. | `src/LandStack.Api/Infrastructure/Data/Models/ToDoItem.cs` |
| Item ID | GUID identifying a to-do item; C# `ToDoItemId`, SPA `toDoItemId`, route parameter `toDoItemId`, method argument `todoItemId`. Serialized as a string in the SPA model. | `src/LandStack.Api/Infrastructure/Dto/ToDoItemDto.cs`; `src/LandStack-Spa/src/app/_models/toDoItemDto.ts`; `src/LandStack.Api/Controllers/ToDoItemController.cs` |
| Completion | `IsCompleted` / `isCompleted`; toggling inverts the stored boolean. This is not a separate status workflow. | `src/LandStack.Api/Infrastructure/Features/ToggleCompleteTodoItem.cs` |
| Created date | `CreatedDate` / `createdDate`, set on new items from `TimeProvider.GetUtcNow().UtcDateTime`. REST JSON serializes UTC; SignalR keeps its own JSON date handling. Historical stored instants are preserved. Generated TypeScript `Date` does not itself convert JSON strings. | `src/LandStack.Api/Infrastructure/Features/CreateTodoItem.cs`; `src/LandStack.Api/Infrastructure/Services/UtcDateTimeJsonConverter.cs`; `src/LandStack.Api/Program.cs`; `src/LandStack-Spa/src/app/_models/toDoItemDto.ts` |
| Item DTO | Transport shape `ToDoItemDto` containing item ID, description, completion and creation date. Distinct from the persisted record. | `src/LandStack.Api/Infrastructure/Dto/ToDoItemDto.cs`; `src/LandStack.Api/Infrastructure/Data/Models/ToDoItem.cs` |
| Create-item DTO | `CreateTodoItemDto`, containing only `Description` / `description`; the server assigns ID and creation time. | `src/LandStack.Api/Infrastructure/Dto/CreateTodoItemDto.cs`; `src/LandStack.Api/Infrastructure/Features/CreateTodoItem.cs` |
| Feature handler | Local typed request/handler pair implementing list, create, toggle or delete, shared by HTTP controller and SignalR hub. Examples: `GetAllItemsRequest`, `CreateTodoItem`, `DeleteTodoItem`. | `src/LandStack.Api/Infrastructure/Dispatcher/Contracts.cs`; `src/LandStack.Api/Infrastructure/Features/`; `src/LandStack.Api/Controllers/ToDoItemController.cs`; `src/LandStack.Api/Hubs/ToDoHub.cs` |
| REST view | UI labeled `Rest` at `/`; `TodoRestService` calls `/todoItem`, refreshes its list after mutations, and posts toggles to `/todoItem/toggleComplete/{id}`. Server controller route is `[controller]` on `ToDoItemController`. | `src/LandStack-Spa/src/app/todo-rest/todo-rest.component.ts`; `src/LandStack-Spa/src/app/todo-rest/todo-rest.service.ts`; `src/LandStack.Api/Controllers/ToDoItemController.cs` |
| Realtime view | UI labeled `Realtime` at `/realtime`; `TodoRealtimeService` connects to SignalR, obtains the initial list and updates local state from events. | `src/LandStack-Spa/src/app/todo-realtime/todo-realtime.component.ts`; `src/LandStack-Spa/src/app/todo-realtime/todo-realtime.service.ts` |
| To-do hub | SignalR endpoint `/todohub`, implemented by `ToDoHub`; methods `GetAllItems`, `Create`, `ToggleComplete`, `Delete`. | `src/LandStack.Api/Program.cs`; `src/LandStack.Api/Hubs/ToDoHub.cs` |
| To-do notification | Internal local `INotification` named `TodoNotification` with `Action` and `Data`, relayed to all hub clients by `NotificationHandler`. Mutations await `Notify`; a send failure after a write does not roll back storage. | `src/LandStack.Api/Infrastructure/Features/Notification.cs`; `src/LandStack.Api/Hubs/NotificationHandler.cs`; `src/LandStack.Api/Infrastructure/Dispatcher/Dispatcher.cs` |
| Notification action | C# `NotificationAction.ItemCreated`, `ItemUpdated`, `ItemDeleted`; emitted hub event names and generated SPA enum members are `itemCreated`, `itemUpdated`, `itemDeleted`. Creation data is an item DTO, update data is an updated persisted item, deletion data is the item ID. | `src/LandStack.Api/Infrastructure/Dto/NotificationAction.cs`; `src/LandStack.Api/Infrastructure/Extensions/EnumExtensions.cs`; `src/LandStack.Api/Infrastructure/Features/CreateTodoItem.cs`; `src/LandStack.Api/Infrastructure/Features/ToggleCompleteTodoItem.cs`; `src/LandStack.Api/Infrastructure/Features/DeleteTodoItem.cs` |
| LiteDB provider | Singleton `LiteDbProvider` defaults to content-root `App_Data/database.db`, configurable with `LiteDb:DataDirectory`; handlers use collection `ToDoItem`. Compose persists the directory in volume `appdata`. | `src/LandStack.Api/Infrastructure/Services/LiteDbProvider.cs`; `src/LandStack.Api/Infrastructure/Services/LiteDbOptions.cs`; `src/LandStack.Api/Infrastructure/Features/GetAllItems.cs`; `docker-compose.yml` |
| Generated models | Tracked TypeScript DTO interfaces and notification enum under `_models`, generated by MTT from C# DTO sources. API-only builds use intermediate `TypeScriptModels` output when the sibling SPA is absent. | `src/LandStack.Api/LandStack.Api.csproj`; `src/LandStack-Spa/src/app/_models/`; `tools/contract-generation/README.md` |
| Busy state | `BusyService` counts pending work and exposes an observable UI busy flag; `busyStream`, `busyCombine`, `busy`, `idle` wrap operations and release pending work on completion, error or cancellation. | `src/LandStack-Spa/src/app/busy/busy.service.ts`; `src/LandStack-Spa/src/app/busy/busy.component.ts` |
| SPA | Standalone Angular app `LandStack-Spa`, bootstrapped through `appConfig`; the application builder emits browser assets. Nginx serves those assets and falls back to `index.html` for client routes. | `src/LandStack-Spa/src/main.ts`; `src/LandStack-Spa/src/app/app.config.ts`; `src/LandStack-Spa/angular.json`; `src/.docker/_spa.dockerfile` |
| Hub connection factory | Injectable `TODO_HUB_CONNECTION_FACTORY` creates the configured real SignalR connection at runtime and accepts fake connections in tests; `TodoHubConnection` is its narrow contract. | `src/LandStack-Spa/src/app/todo-realtime/todo-hub-connection.ts` |
| Frontend unit tests | Angular's unit-test builder runs Vitest with jsdom and mocked transports. Its test configuration uses zoneless TestBed while the application runtime retains Zone.js. | `src/LandStack-Spa/angular.json`; `src/LandStack-Spa/tsconfig.spec.json`; `src/LandStack-Spa/src/app/app.component.spec.ts` |
| Local dispatcher | `IDispatcher` / `Dispatcher` resolves one typed handler for each `Execute` request or void command and fans out awaited `Notify` notifications within the current DI scope. Replaces the former MediatR dependency. | `src/LandStack.Api/Infrastructure/Dispatcher/` |
| Health endpoint | `/health` reports minimal application liveness without opening the database or asserting storage readiness. | `src/LandStack.Api/Program.cs` |
| OpenAPI document | Built-in REST API description at `/openapi/v1.json`, exposed only in Development. | `src/LandStack.Api/Program.cs`; `src/LandStack.Api/Controllers/ToDoItemController.cs` |
| Failure response | REST uses Problem Details for validation, not-found and unexpected errors; the hub returns safe `HubException` messages. Missing delete is a successful no-op without notification. | `src/LandStack.Api/Infrastructure/Features/TodoErrors.cs`; `src/LandStack.Api/Infrastructure/Services/TodoExceptionHandler.cs`; `src/LandStack.Api/Hubs/TodoHubFilter.cs`; `src/LandStack.Api/Infrastructure/Features/DeleteTodoItem.cs` |
